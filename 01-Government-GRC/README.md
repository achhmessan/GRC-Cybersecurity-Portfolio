# Government GRC Projects

This section documents hands-on cybersecurity Governance, Risk, and Compliance (GRC) projects focused on U.S. government security requirements.

## Frameworks and Standards
- NIST Risk Management Framework (RMF)
- NIST SP 800-53 Rev. 5
- FedRAMP and GovRAMP
- FISMA
- DISA Security Technical Implementation Guides (STIGs)

## Planned Projects
1. NIST RMF Security Categorization
2. System Security Plan (SSP) Development
3. Security Control Assessment
4. Plan of Action and Milestones (POA&M)
5. Authority to Operate (ATO) Simulation
6. Continuous Monitoring Assessment

All projects use simulated environments and fictional organizational data for educational purposes.
